# 可选需求来源：飞书月度任务

默认使用聊天中提供的主题与需求，不绑定任何私人文档或多维表格。用户明确提供飞书来源时，再用已安装的 lark-doc / lark-base 技能读取；没有授权不读取、不回写。

- 由用户提供文档链接，或 Base 的链接、table_id 与 view_id；不把其他用户的 token、记录 ID 当作默认配置。
- 可映射字段：时间、主题、风格选择、黑板长、黑板高、参考素材、状态。以实际表结构为准。
- 黑板长、高可能含“厘米”等单位，需解析单位；缺尺寸不能猜测。
- 多维表格附件通过对应附件接口读取，不当成 Docx 图片。
- 每次重新读取记录、尺寸和状态；不把历史月份当作当前任务。
- 仅对用户已指定来源的正式生产应用“开始制作”状态门槛；聊天中的直接授权不受此门槛约束。
- 聊天中明确的新修订优先于旧记录；不预置个人配色或主题偏好。
