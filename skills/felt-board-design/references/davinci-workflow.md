# davinci 与实体黑板报的工作约定

## 启动和实际能力

读取已安装 `davinci` 技能获取完整命令。运行 `davinci projects --json`、`davinci --help`、`davinci schema`；所有生产操作显式指定项目和画板。若 PATH 未生效，在本仓库运行 `cd editor && ./start.sh install` 安装本分支 CLI。缺失环境时按本仓库 README 构建；上游发行版可能不包含本分支的打印增强功能；不用静态 HTML 冒充已运行编辑器。

来源：https://github.com/ChrisZou/davinci 。本次参考 main 的 README、完整 davinci skill 及其命令/封面规范、文档模型、命令 schema、配色与 shape 实现、layerize 说明。主分支不等于已安装发行版；运行时 schema 优先。1.1.0 已验证支持图层、线条、编组和多画板；其 CLI 无 palette 子命令。不要为补齐主分支功能覆盖可用工程。

## 画布、布局与单位

黑板报使用自定义长宽，不能套自媒体封面预设或“最多两行文字”等封面规则。保存实际板面厘米、比例、纸型、原点和边缘限制。推荐 20 画布像素/cm：400×104cm 对应 8000×2080px，x/y/字号/描边都按统一比例映射。此比例是工程单位，不是图片 DPI。原图 2172×724 与板面不同宽高比，应单设原图画板。

一个主题一个项目：参考原图、当前设计、备选版本、打印排版可各用画板。保留旧版不覆盖。背景和定位辅助线锁定；辅助标记不进入打印导出。用户可在编辑器中拖动、缩放、旋转、调整层级；需要操作组内元素时按实际版本先解组，改完恢复组并更新 ID 映射。不要假设组内图层可直接被 CLI 寻址。

## 图层结构与打印结构

稳定语义键与 davinci 实际 layer ID 分别保存。建议 `T01-文明-字1`、`T01-文明-字2`、`D01-太阳`、`S01-程门立雪-标题/正文/插画/提示/底板`；各图层名称唯一。锁定不代表不可编辑，提供解锁说明。

编辑图层保存文字内容/字体/样式，图片源路径与素材库资产引用，几何、层级和可见性。印刷单元另存其引用图层列表、成品宽高 cm、数量、纸型、拼接行列、重叠宽度、位置与页码。修改正文不重画插画；换插画不覆盖底板；改底板尺寸不把正文拉伸。打印时导出组合，工程仍保存分层。

## 文字、线条和异形

精确中文用 addText/setText/setTextStyle 等原生文字；记录字体族、字号、字重、字距、行高、折行宽度、描边、阴影。字体须已安装或按许可随工程提供。改字后重新渲染检查缺字、换行和溢出。文字框 width 控制换行，不用 height 改字号。艺术字用原生描边/投影/斜切/梯形等实际支持的效果；原图艺术字暂时只能原样位图时注明，不能声称双击可改。

线条用实际 schema 中的 line、strokeWidth、lineStyle、arrow；装饰路线、分隔线、印刷定位线分开。检查旋转与整体尺寸。异形背景复杂时使用独立透明插画或适用的矢量素材；不假设 davinci 支持任意可编辑路径。简单形状与照片效果不能替代用户需要的绘本插画。

## 配色库、图片库与模板

色板保存五个角色 bg/text/highlight/text2/accent，并可扩展纸色、线条色和区域色。先分析参考图的面积关系、冷暖与对比，再选颜色，不只提取几个色值；低饱和不等于全板浅色。用户要求小学一年级时保留识读对比和适量明亮重点。

若有 palette：list/show 后选择，from-image --dry-run 预览再保存，apply 后检查。apply 改文字和形状，不会重新绘制插画中的颜色；保存配色也不自动绑定之后所有图层。若无 palette：使用 `assets/board-palettes.json`，将角色色落实到图层样式，保留可复用文件，明确这是文件配色库。

素材库管理插画、背景、装饰及来源；图片可替换、裁剪恢复、描边、阴影、滤镜，均按 schema 核对。背景移除先保留原图；不得把去背景当语义分层。模板库收藏原生图层工程，不收藏仅一张整图的伪模板；从模板复制新稿，不覆盖模板。

## 迁移已有成片

先做语义清单和一块完整试迁移：参考板保留原图；设计板依次迁移底板、标题、正文、插画、提示和装饰，逐项对比颜色、轮廓、位置、尺寸及纹理。用户要求原样时只处理有依据的部分，缺失区域标记待处理，不以相似新图替代原图却称无差异。

上游 tools/layerize 可辅助 OCR、字体近似匹配、分割和背景修补；它依赖 Swift Vision、rembg、LaMa 等，不随桌面 App 保证可用。先核查依赖；不得为此默认下载大型模型。OCR 内容须人工校对，重建字体须视觉复核；图像修补和字体拟合均不是原图无损恢复。文字转为原生层后必须擦除/修补底图旧字，否则修改后露出旧字；不能同时展示参考底图旧字和新字。

## 编辑、导出与打印

操作前保存工程快照，读取当前图层，批处理使用 exec --file；同一批一撤销步骤。改后用实际工程 render 并看图。给用户 davinci open 返回的真实编辑器地址，禁止猜项目 URL。保存可迁移的完整项目 JSON 和图片资产；JSON 中 /assets 引用必须随包解析并携带，单有数据库路径不是可携带工程。

按 print-spec 生成 PDF。davinci 的 PNG/JPG/WebP 导出不等于厘米 PDF；渲染倍率最大 8。20px/cm 的原生文字按 300dpi 导出时倍率约 5.9055，逐件导出避免整板超大图；位图仍按原始像素核算有效 DPI，放大倍率不会补回细节。

同一工程快照生成整板图、单件图、印刷 PDF 和清单；导出指定图层组合，避免邻近装饰被带入。物理成品尺寸包含裁剪白边。A3 297×420mm / A4 210×297mm，按打印机实际可打印边距排版，不能缩放适应页面。两字一A3只是该主题用户选择，先核对两字实际成品外框是否装得下；超纸按已授权拼接，保留毫米重叠和对位标。绘本内部细节整体印在纸片里，仅裁宽松外轮廓。

## 验收

实际执行一次只改文字、一次换图、一次移动并撤销，读取工程核对其他元素未改变；渲染看效果。导出一个组合单件，检查透明边界与厘米尺寸，再渲染一张真实纸型 PDF。确认编辑图层数、打印件数、打印页数可以不同且对应清晰。没有运行环境只交付技能/规格时如实说明，不能说已完成可拖拽工程。

## 与五阶段技能的衔接

DaVinci正式分层发生在阶段五；阶段二的布局规划图需要真实展示，不能以最终工程渲染倒替它。此前生成的完整成品仅是批准视觉参考，真实素材重组及工程渲染还需保留所有已确认正文。

导入命令按实际schema生成，不能把工程快照字段原样传给add命令。例如实际版本addText可能不接受height，圆角可能保存于style.cornerRadius而导入需顶层cornerRadius；检查实际schema，不硬编码跨版本假设。

portable素材包用相对路径含全部依赖、素材描述、字体清单及图层ID映射。需要宣称可恢复时实际重建并对比；不能只因JSON存在就说可恢复。对比文字、几何、层数与渲染；本机字体相同时可以进一步做逐像素核对。

## 分层与打印验收：防止切图冒充分层

- 图层数量、矩形 cropImage 和去背景成功不是语义分层证明。独立件应有完整轮廓和真实透明外部；隐藏底板检查矩形残底，移人物检查邻件，改字检查烘焙旧字。艺术字或故事场景保留位图时说明内部不可编辑。
- 区分编辑对象、裁切单元、打印页面。省纸排版只排列已有素材，不能修复内部结构或增加源细节。超大件跨页如实标为拼接。
- 用户需要继续编辑A3时，提供保留原生文字/图形和独立图片的原生画板，以及包含源素材的可恢复工程包。PDF矢量字形路径、逐页截图或PNG不能代替可改字工程。
- 排版算法测试通过不代表素材通过打印验收。按真实源像素和实物厘米记录DPI；先用一个完整模块验证改字、移动、隐藏、替图、撤销及包恢复，再批量制作。
- 缺素材明确报错，不以占位矩形代替后宣称导入完成。在新画板验证并核对原稿不变。CLI带-b会将命令数组内每条命令绑定原画板；跨画板批次用一个外层batch对象，或给后续命令明确新画板ID，不能继续盲用原-b。
