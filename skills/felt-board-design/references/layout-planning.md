# 独立的布局规划阶段

## 交付一张真图

阶段二发生在内容确认后、视觉草稿前。必须有实际可查看的PNG/SVG，且在聊天中展示。可用本技能脚本：

```bash
python3 scripts/render_layout.py --input /absolute/task/02-layout.json --out-dir /absolute/task/layout
```

脚本使用Pillow制作PNG（需要环境可用Pillow），同时输出保留比例的SVG（厘米坐标以JSON为准）、位置CSV及检查报告。调用前从本技能目录解析脚本路径，不依赖当前工作目录。可用 `--font` 指向支持中文的.ttf/.ttc；缺字体或Pillow时报告实际依赖，并使用等效确定性绘图工具，不能退回纯文字方框冒充图。

参考 [完整示例](../examples/layout-example.json)。示例仅说明数据与展示，不是默认布局模板；不要把示例尺寸、六块结构和形状套用于所有主题。

## 图上应看见什么

- 真实板面宽高和比例、可用范围、边距、固定遮挡。
- 主标题及其占区，各模块编号、名称、形状和外接尺寸；必要时另画安全文字区和插画预留区。
- 每块的内容类型/正文量或简要摘要、阅读先后，以及主要裁切分组。
- 哪些模块是一个大区的子块，哪些装饰会跨区，文字是否在异形的安全内区。
- 图上印“布局规划图｜不供1:1打印”，防止把规划稿误当成素材或最终效果。

布局图的颜色用于区分功能与层次，不是未经讨论冻结最终配色；可按已有参考配色。坐标表是图的补充，不是替代。

## 结构选择与面积分配

先以已确认的正文量和主视觉安排面积。长故事需要较大的安全文字区；短提示可用窄贴片。板面很宽时可采用多段错落结构，不把同一段正文拉成长行。

左中右仅是大方向。可以左侧故事、中间主题主场景、右侧知识；也可以三大区含五六子模块。对变化较大的结构，用两张比例相同的规划图对比主次和阅读路径。没有实际取舍时不强行生成两版。

异形标题和模块要在规划图显示轮廓。书本、六边形、叶片、旗帜、云形、开放场景可组合，但形式为内容服务；避免每块都使用同一云朵、所有区域等宽等高、文字被尖角和装饰挤压。异形规划轮廓只是造型方向，成品阶段还需优化。

正文实际字高根据阅读距离、年级与板面决定；用户未给阅读距离可把假设写在图边。用拟用字体、字高、行宽和完整正文测量文本占区；文字放不下时协商精简或扩大，不用缩略图看似可读来证明实物可读。脚本检查几何和标签，不自动证明阅读距离或正文容量已合格。

## 数据与检查

JSON关键字段：

- `board`: width_cm、height_cm、margin_cm、background。
- `title`: id、title、x_cm、y_cm、width_cm、height_cm、shape。
- `modules`: 每块id、title、同样的几何字段、shape、summary、content_chars、cut_group；可给group、reading_order、text_box和illustration_box。
- `text_box`/`illustration_box`: 模块内部的相对厘米x/y/width/height；矩形仅为区域预留，不是插画素材。安全文字区需人工检查是否位于异形轮廓可读内区。
- `exclusions`: 固定遮挡，几何字段为板面绝对厘米坐标。
- `allowed_overlaps`: 明确允许重叠的模块ID对；只表示经过设计，仍需确认不遮正文。

无旋转的外接框、有限正尺寸、板面边界及遮挡相交由脚本检查；旋转和复杂裁切轮廓请另做几何计算。正文或插画可能超框时必须更新坐标，不能让渲染时裁切掩盖错误。边距或外接框重叠会报告为提示，允许的背景重叠单独记录。阅读箭头为规划辅助，不进入最终打印。

## 确认与变更

交付图后用一个具体问题确认，例如“采用这版六块错落布局，还是把故事区加宽？”不要问用户重复确认已批准正文。

内容改变则重新评估空间；布局改变则更新图和版本；草稿/成品与布局不同时指出差异并回到受影响的确认点。确认记录中保存布局图路径和版号，不能仅写“已确认”而没有真实用户依据。
