# 独立素材、demo 和提示词

本参考用于主技能阶段五：内容、布局图、草稿和成品效果已按授权范围确认后，才制作正式分层素材。每块完整正文是素材的一部分，不在拆件或导入时删成标题与一句口号。

## 一份项目台账贯穿全流程

每件描述同时保存位置、颜色、尺寸、字体/字号单位、旋转、透明度、层级、分组与可见/锁定；未定值明确标记原因。源图片文件、原像素和可编辑边界也需说明。

采用稳定素材编号（如 T01 标题字、C01 内容块、D01 装饰），并区分可复用的素材与每次摆放实例。清单是布局、demo、源文件及打印页的共同数据源，不凭肉眼在不同输出里各自重排。

目录建议：brief.md、layout.csv、assets/、demos/、prompts.md、manifest.csv、preview/、print/；按任务规模合并文档，不创建空占位文件。制作中记录状态：待设计、demo 完成、源文件完成、已排版、已检查。尚未完成的项明确标记，不虚报整包完成。

## 内容分块

每块记录：编号、标题、精确正文、教育目的、主次层级、预留区域、对应素材编号。标题和正文先校对再制作；文字调整要同步所有成品。儿童内容短而具体，使用适龄语言，不为适配纸张无限缩字。

## 每件素材的设计卡

每个独立素材必须提供：

- 编号、名称、所属板块、数量及用途。
- 成品裁剪宽高 cm、图案尺寸、白边、纸型，尺寸未定则明确标识。
- 真实 demo 图及源文件链接。透明素材的 demo 可用棋盘格/板底色预览，正式文件保留真实 alpha；带尺寸标注的 demo 不混入打印成品。
- 文字原文、配色、轮廓、裁剪注意事项。
- 可直接复制的完整提示词及避免项，不写“同上”“照上一张”。使用参考图时写清依赖哪个文件，不能假称纯文字能完全复现。
- 制作方法、像素尺寸、有效 DPI、打印页码和当前完成状态。

相同素材重复使用可共享一张设计卡，但列明数量和所有摆放实例。不同字形是不同素材，不能只交一张标题 demo 代替全部字。

## 提示词模板

为每件素材保存适合实际制作的中文提示词，必要时附英文版本：

> 素材编号：[ID]。用途：[板块与对象]。主体：[具体内容/动作]。风格：[统一的造型、色彩和描边]。构图：[完整、独立、四周留裁剪余地]。背景：[真实透明/指定实色]。文字：[精确原文，或无文字，后期矢量排版]。裁剪：[宽松闭合轮廓、连接强度、白边]。保留：[参考图的必要特征]。避免：[裁切、额外元素、环境投影、错字等针对性限制]。

厘米规格写在设计卡和排版参数中；不能依赖模型画出尺标或在提示词里写 300 DPI 就声称满足打印要求。提示词要求高清后仍须检查实际输出像素。

中文标题、正文优先用支持中文的字体矢量排版；可生成不带字的装饰底形，再合成准确文字。只有文字造型本身必须图像生成时才采用带字生成，并逐字核对。对矢量素材，提供可复现的字体、字号、填色、描边和排版参数；提示词用于说明设计，不必为了满足“提示词”强制调用生图。

## 原图拆件与清晰度

已有海报先列出可独立提取、相互粘连、被遮挡的素材。保留形状做抠图/透明底提取；被遮挡部分需补画时明确说明。若用户要求改设计或重绘，使用已锁定的图片执行渠道（见image-provider.md）；用户只要求保留原样时不默默整图重绘。任何方法都要逐字检查中文。

原图放大与重新绘制分开记录。普通插值、修改 DPI 元数据或同像素重绘都不算提高真实细节。没有可用超分辨率工具时，可缩小实物尺寸、分件重做或报告限制；不得宣称生图工具保证原样无损放大。超分输出记录原始和输出尺寸，并检查笔画和伪影。

## demo 到打印

在主题内容和板块成片方案已由用户反馈确认后，执行：独立素材源文件 → 每件 demo → 按厘米坐标合成整板预览 → 同源排版打印 PDF。不得跳过板块设计直接批量出素材。可以先用风格样张探索，但必须标为概念样张；交付时以实际素材合成图替换，不拿无法落地的概念海报冒充最终效果。

用户既定 A3/A4 持续有效，不能为方便换纸型或改变成品尺寸。两种纸均允许时按节纸和易拼贴选择，并说明。默认按既有规范单件一页；用户要求节纸可多件同页。超纸张素材优先在设计阶段拆为自然独立件；需要跨页拼接时先提供成品尺寸、拼接页数和重叠方案让用户选择，不以自动缩小代替决定。用户已授权拼接则直接执行，添加页序、对齐标记和约 5–10 mm 重叠区，并将其计入排版检查。

只生成文件不等于实际打印。除非用户明确要求并提供可用打印机入口，否则交付可打印 PDF 与 100% 实际大小说明，不声称已送印。

## 风格继承

若任务已选择felt毛毡预设，代表模块复核要按[felt-picturebook-style.md](felt-picturebook-style.md)检查材质、艺术字、大人物、短句贴片与少装饰原则。不要将完整效果简化成普通文字+纯色框+微型插画。
