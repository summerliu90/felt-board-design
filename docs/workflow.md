# 工作流、编辑与打印

1. **内容规划**：确定主题、年级、用途和准确文案。没有真实尺寸时可先策划，不能猜尺寸制作正式布局。
2. **比例布局**：按板面厘米尺寸绘制布局图，检查阅读量、模块大小、裁切分组和固定遮挡。
3. **草稿与成品**：确认构图与风格后再生产整套素材；已授权连续制作的范围无需重复确认。
4. **独立素材与导入**：先核对一个完整模块，再完成其余模块。标题正文尽量原生文字，独立人物与底板分件制作，保留素材 ID、位置、尺寸、颜色、源像素、图层映射与编辑边界。
5. **网站编辑**：通过 CLI 导入真实素材与原生图层后，在同一网站拖动、换图、改字。继续工作前读取最新工程，不用旧快照覆盖用户修改。
6. **A3/A4 打印**：打开实际尺寸打印工作区，选择纸型、方向、边距和间隔，按需允许 90° 旋转。“全选加入打印”加入可见顶层图层，各层保持独立；需一体打印时先选择相关层合为一件。
7. **自动编排与微调**：自动安排大小不同的素材，保留实际厘米尺寸。可手动调整完整素材位置；超大素材会拼接分块。批量移除与清空仅清打印列表，不删除源图层。
8. **保存和输出**：PDF 用于打印；可编辑工程包用于继续编辑或迁移。生成可编辑打印画板后仍可调整图层；不要只保存预览 PNG 当作源工程。

打印使用“实际大小 / 100%”，先检查校准线并试打一页。纸张留白、拼接重叠、素材比例会影响页数；减少细碎装饰也能减少剪贴工作。DPI 警示依据源像素与计划尺寸，修改 DPI 标签或放大画布不等于补出细节。
