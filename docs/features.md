# 功能与发布边界

## 当前源码包含

- 浏览器图片编辑、原生中文文字与形状、多图层与多画板、素材库、撤销重做。
- 以厘米保存板面物理尺寸；源像素与打印尺寸分别计算。
- A3/A4 实际尺寸打印，旋转与多次排序的 MaxRects 自动编排，超大素材拼接。
- 全选加入打印、选中图层合为一件、打印列表勾选、批量移除、清空。
- 可编辑打印画板、携带素材的工程包导出与恢复、实际尺寸 PDF。
- 网页品牌图标与字标移除；命令名称和内部协议保留。
- felt-board-design 八种风格、准确文案、五阶段设计与素材交接规则。
- Lemon 单件生图桥接、无计费自检、版本缓存、透明 PNG 和源 DPI 检查。

## 不应当宣传成已完成

- 网页直接一句话完成整套黑板报、Lemon 持久化后台队列和自动进度同步。
- 从整图无损提取所有人物、文字与任意细节图层。
- 自动排版一定全局最省纸，或低清图片放大即可达到真实高清。
- 已部署可公开访问的多人云服务。

## 发布整理

仅收录产品源代码、技能、示例、原项目资料和许可证。排除运行数据库、账号配置、API 密钥、构建二进制、依赖目录、制作过程日志、私人飞书来源及具体班级工程。本仓库的 Skill 使用可配置路径，作者本机已安装 Skill 与正在运行的网站没有被覆盖。
